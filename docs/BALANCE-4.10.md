# Combat and economy candidate

Release 4.10.0 retains the production 4.9.1 lossless WebP atlases and Android extraction constraints. It changes neither character art nor animation. The full-character outfit and rewarded-ad system is separate work.

Currency: two separate balances. Existing save key `gold` remains ordinary spending money G; `stones` is renamed in the UI to rare upgrade gold. No conversion or merging of balances occurs. Existing stone counts become the same number of upgrade gold, with existing G unchanged. Normal monster gold chance 10% for 1 unit, elite 25% for 1, boss guaranteed 3. Normal monster rewards and equipment sale proceeds remain G. HP potions cost 50 G; MP potions cost 60 G. Existing gold/stone save keys are retained for compatibility.

Forge upgrades each equipped weapon/armor/accessory to +15 using rare gold only. Cost = 2 × (current plus + 1) + item tier, starting at 2 gold for tier-zero +1. Each step uses the existing itemStats +8% base multiplier and succeeds without item loss. Server validates equipped slot, home location, balance and cap. Existing character-wide legacy +20 enhancement stats remain intact; its compatibility command now spends rare gold (3 + 2 × current level), while the new forge exposes item upgrades. No G-to-gold exchange is offered. Preserve current level and the fraction of XP completed within it; legacy saves receive five MP potions. Starting money remains 100,000 G.

Normal monster HP = round((110 + 65L + 1.4L²) × (1 + 3 × (1 − exp(−(L−1)/10)))). Damage = round(12 + 5L + .09L²), before player defense. Species retain their toughness, speed and attack patterns. Elite HP ×2.6, damage ×1.2, XP ×3; boss HP ×7, damage ×1.65, XP ×10. Fixed level-based stats do not scale with the player's equipment, so upgrades retain their value.

Normal XP = 20 + 8L. XP required = normal XP × round(8 + 1.2L + .006L²). Same-level normal kills per level: 9 at L1, 21 at L10, 49 at L30, 102 at L60, 165 at L90, 238 at L120. Current maps cover 1–120, although the existing player cap remains 210. No new endgame content is included.

Skills: cooldown ×0.8 (minimum 1.5 seconds before quick modifier), modifier MP surcharge reduced from 8 to 4. MP regen 6.5 + min(6, INT × .02) per second. All four starting class skills can be sustained; rotating several skills spends reserves and makes MP potions useful. MP potion costs 60 G, restores 50%, cooldown 6 seconds independent of HP potion. Server rejects use when dead, full, empty or on cooldown and purchases outside town/home. HP potion remains 50 G, 50%, cooldown 4 seconds. Mobile MP button plus T shortcut; labeled red HP, blue MP, yellow EXP bars.

## Evidence and limits

Run `node tools/balance-report.mjs` to reproduce balance-estimates.csv. Representative build allocates 4 STR / 3 VIT / 2 INT / 1 AGI per level, equips blue gear at its level tier, and trains the first three skills within its point budget. Estimates use average stationary DPS including cast time opportunity cost, but omit travel, misses, critical skill variation, area damage and damage over time. They are not measured time-to-kill. Unspent builds deliberately struggle; gear and skill training should be taught clearly in playtesting. Species toughness changes kill time by 0.75–1.7×.

83 automated tests pass (core, progression, skills, runtime, advanced world, gear, auto-hunt and balance). Tests include one-time migration, purchase boundaries, authoritative MP use and 480 class/level cases. Browser validation at 844×390 passes: HUD, MP button bounds, shop purchase using G, forge gold balance, disabled insufficient-gold upgrades, save reload, no missing assets or JavaScript errors. Physical phone/ad tests have not been run. Existing online field-skill handling differs from offline repeated ticks and needs separate parity work before claiming identical combat balance. The backend bundle was rebuilt successfully. Full suite: 83/83 pass after restoring production assets. Online integration tests pass. Stage both client and bundled backend and run live smoke tests before release; do not publish this client against the old backend.

Currency correction tests cover drop thresholds, independent balances, equipment stat growth, save round trip, upgrade caps and server-side location/fund validation. Release includes server-side migration before welcome, persisted once, with legacy currency balances and XP progress retained.
