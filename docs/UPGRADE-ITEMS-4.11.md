# COCKRO 4.11.0

Five equipped skill slots replace three. Previous slots remain intact; newly added slots automatically select learned, unequipped skills when migrating old three-slot saves. Skills retain level unlocks. Keyboard 1–5 and auto combat use all five; server validates slot 0–4. Mobile buttons were tested at 844×390 and 640×390 with no overlapping bounds.

Upgrade items use rare gold (`stones`) rather than spending G (`gold`). All begin at zero and persist under `upgradeItems`. Prices: meteor 20, crystal 35, glowstone 35, diamond 60, ruby 40 gold per item. These intentionally cost about 200–600 same-level normal kills at the existing 10% gold drop rate; bosses shorten that time.

Meteor (หินอุกาบาศ) is required for each +1 item upgrade in addition to the existing rare-gold cost. Existing +levels remain unchanged. Crystal adds 8 attack, glowstone 4 defense, diamond 0.5 percentage points crit chance, ruby 60 HP to the selected item. Each use consumes one item. Each gem type caps at 10 per equipment item; character crit still caps at 50%. All eight equipment slots support enhancements. Enhancements persist through bag/equip/reload and stop contributing when the equipment is removed. Selling equipment removes its enhancements with it; gemstones are consumed, not refundable.

Artwork: built-in Imagegen, five separate square premium fantasy RPG inventory renders. Final web assets: web/items/meteor.webp, crystal.webp, glowstone.webp, diamond.webp, ruby.webp. Converted to 256×256 WebP for Android patch compatibility, total under 80 KB. Prompt theme: centered polished hand-painted 3D object occupying 70% of square canvas, top-left lighting, dark navy background, no text/frame/pedestal. Subjects: dark meteorite with molten orange fissures; violet crystal cluster; blue rune stone; icy white diamond; crimson ruby.

Rewarded ads are NOT live. Inspection of MainActivity.java and app/build.gradle at release 4.10.0 confirms there is no advertising SDK or reward bridge in the installed Android host. A web patch cannot add a native SDK. Shop shows disabled 'watch ad for 1 item' controls and an honest unavailable status; no simulated videos, timers or client-only claims grant items. The server rejects forged adReward operations. Native SDK integration, actual AdMob application/rewarded placement configuration, consent handling, authenticated server-side reward verification/deduplication and a signed native app release are still required before enabling this path. Browser purchases and upgrades remain usable.

Validation: 89 Node tests pass including five-slot migration/casting, currency isolation, atomic consumption, gem caps, accessory upgrades, equipment persistence, server location checks and forged ad rejection. Browser smoke covers five visible nonoverlapping skill buttons, five illustrated shop items, buying all five with rare gold, meteor forging, crystal/ruby enhancement and reload. Physical Android performance and actual rewarded ads have not been tested.
