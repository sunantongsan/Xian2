# COCKRO 4.31.0 audio update

Replaces active oscillator beeps and the shared skill explosion with adapted Pixabay recordings. Sources, authors, original checksums, license URL, and derivative mapping are in web/audio/credits.json. Music is marked AI-generated by its contributor. Assets are incorporated into the game, not offered as a standalone sound pack.

Five effect families follow actual skill form (wave, dash, bolt, circle, field), with class/skill-specific pitch. Own-player accepted combat events trigger audio in PvP and PvE; rejected casts do not. Offline skill playback uses the same mapping. Tap, hit and reward feedback use short quieter clips. Welcome, character creation and world scenes have separate excerpts of the ambient track. Music waits for first user interaction; the welcome screen includes a mute button. All channels pause when muted or the page is hidden, with at most three simultaneous effects and duplicate throttling.

Validation: 196 Node tests passed. Local headless browser with real test websocket server verified five automatic and five manual PvP skill slots, decoded audio readyState=4, movement preserving target, and no page errors. Audio clips decoded with ffmpeg; effect files have fades and peak limiting. This is not an on-device listening assessment.
